# 330 C# Programming

**Format:** One program, 90 minutes. You bring your own computer with one of these IDEs: Visual Studio 2022, Visual Studio Code. Graded on: does it run (if it does not run, the execution section scores zero), does it do what the spec says, and source code review (comments, naming, required functions). Put your contestant ID in a comment at the top. Use relative file paths only.
**Reference materials in the real test:** **Yes, including printed code.** You may bring printed reference materials and printed pre-written code. Nothing electronic, no online interpreters.
