# BPA 330 C# — Timed Build 2: Food Truck Sales

## Overview
A 90-minute production task in the shape of the real event. You get a pre-built Windows Form with empty button methods, a data file, a problem, and a rubric. Write the code behind the buttons, make sure it runs, push it.

This build uses everything from Steps 1–11: a class, a list of objects, reading a CSV file, validated input, a formatted table, a report file with the date and time, and the Windows Forms skills from Step 11. If you finished Step 11 (Club Manager), you have already written most of the pieces once.

**Time Estimate:** 90 minutes

**What you need:**
- [Problem](TimedBuild02_Problem_FoodTruck.md) — read it all before you type anything
- [Starter files](starter/) — `Form1.cs` and `Form1.Designer.cs` (the pre-built form)
- [Data file](sales.csv) — `sales.csv`, add it to your project with Copy to Output Directory = Copy if newer
- [Rubric](TimedBuild02_Rubric.md) — this is how it is graded
- The [330 C# reference guide](../../330_CSharp_Programming_Reference_Guide.md), printed. You may bring printed references and printed code into the real event.

---

## Part 1: Build (graded)

1. Make a folder named **`csharp_timed02`** in your `bpaPrep` repo. Create a Windows Forms App named **`TimedBuild02`** in it.
2. Replace the project's `Form1.cs` and `Form1.Designer.cs` with the starter files, and add `sales.csv` (see Setup in the Problem file).
3. Build to the spec in the Problem file. Put your name in a comment at the top of `Form1.cs` (at the real contest it is your contestant ID).
4. **Input / Processing / Output comments** on every major block, and the `//SC` flags from the rubric. The graders look for them.
5. Save a running version often. **If it does not run at time-up, the execution section scores zero.**
6. No Google, no AI. Printed guide and printed code only.

## Turn It In
