# BPA 355 Python — Week 1: Timed Build

## Overview
A 90-minute production task in the shape of the real event. You get a problem, a starter file, and a rubric. Build it, make sure it runs, push it.

**Time Estimate:** 90 minutes

**What you need:**
- [Problem](week01_QuizTracker/Week01_Problem_QuizTracker.md) — read it all before you type anything
- [Starter file](week01_QuizTracker/QuizTracker_starter.py) — download it and build on it
- [Rubric](week01_QuizTracker/Week01_Rubric.md) — this is how it is graded
- The 355 Python reference guide in this folder, printed. You may bring printed references and printed code into the real event.

Use a local IDE (IDLE, VS Code, PyCharm). Online interpreters are not allowed at the real event.

---

## Part 1: Build (graded)

1. Make a folder named **`python_week01`** and put the starter file in it.
2. Build to the spec in the Problem file. Put your name in a comment at the top (at the real contest it is your contestant ID).
3. **Input / Processing / Output comments** on every major block. The graders look for them.
4. Save a running version often. **If it does not run at time-up, the execution section scores zero.**
5. No Google, no AI. Printed guide and printed code only.

---

## Turn It In

All BPA builds go in **one GitHub repository named `bpaPrep`** in your own GitHub account. Make it once (public, like your class repos). Each build gets its own folder.

1. In your `bpaPrep` repo, make a folder named **`python_week01`**.
2. Put your `.py` file and the results file it writes in it.
3. Commit and push.
4. In the Google Classroom **BPA Friday** assignment, write a private comment: *Python week 1 done*. Include the link to your repo the first time.

---

## Grading

Graded with the rubric, then converted: 90-100 = 5, 80-89 = 4, 65-79 = 3, started but far off = 2, not turned in = 0.
