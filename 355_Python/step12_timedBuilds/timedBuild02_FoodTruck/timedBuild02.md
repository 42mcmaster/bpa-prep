# BPA 355 Python — Timed Build 2: Food Truck Sales

## Overview
A 90-minute production task in the shape of the real event. You get a problem, a starter file, a data file, and a rubric. Build it, make sure it runs, push it.

This build uses everything from Steps 1–11: a menu loop, a class, a list of objects, reading a CSV file, validated input, a formatted table, and a report file with the date and time. If you finished Step 11 (Club Manager), you have already written most of the pieces once.

**Time Estimate:** 90 minutes

**What you need:**
- [Problem](TimedBuild02_Problem_FoodTruck.md) — read it all before you type anything
- [Starter file](FoodTruck_starter.py) — download it and build on it
- [Data file](sales.csv) — `sales.csv`, put it in the same folder as your program
- [Rubric](TimedBuild02_Rubric.md) — this is how it is graded
- The [355 Python reference guide](../../355_Python_Programming_Reference_Guide.md), printed. You may bring printed references and printed code into the real event.

Use a local IDE (IDLE, VS Code, PyCharm). Online interpreters are not allowed at the real event.

## Part 1: Build (graded)

1. Make a folder named **`python_timed02`**. Put the starter file and `sales.csv` in it.
2. Rename the starter file to **`FoodTruck.py`**.
3. Build to the spec in the Problem file. Put your name in a comment at the top (at the real contest it is your contestant ID).
4. **Input / Processing / Output comments** on every major block. The graders look for them.
5. Save a running version often. **If it does not run at time-up, the execution section scores zero.**
6. No Google, no AI. Printed guide and printed code only.
