# BPA 340 Java — Timed Build 1: Rock Paper Scissors Match

## Overview
A 90-minute production task in the shape of the real Java event: exact prompts, exact variable names with your Contestant ID digits, `SC` comment flags, a Scanner, a Random object, a switch, and two while loops. You get a problem, a starter file, and a rubric. Build it, make sure it runs, push it.

**Time Estimate:** 90 minutes

**What you need:**
- [Problem](TimedBuild01_Problem_RockPaperScissors.md) — read it all before you type anything
- [Starter file](RockPaperScissors.java) — download it and build on it (it is already named correctly)
- [Rubric](TimedBuild01_Rubric.md) — this is how it is graded
- The [340 Java Competition Reference](../../340_Java_Competition_Reference.md) and your printed step lessons. You may bring printed references and printed code into the real event.

Use a local IDE (VS Code with the Java extension pack is what this class uses). Online compilers are not allowed at the real event.

---

## Part 1: Build (graded)

1. Make a folder named **`java_timed01`** and put the starter file in it.
2. Build to the spec in the Problem file. Put your name in a comment at the top (at the real contest it is your Contestant ID).
3. For practice, use **`00`** as your Contestant ID digits (so `playerNamexx` becomes `playerName00`), unless your teacher gives you a practice ID.
4. **Input / Processing / Output comments** on every major block, and the **`SC` flags** listed in the rubric. The graders look for them.
5. Save a running version often. **If it does not run at time-up, the execution section scores zero.**
6. No Google, no AI. Printed guide and printed code only.

---

## Turn It In

All BPA builds go in **one GitHub repository named `bpaPrep`** in your own GitHub account. Each build gets its own folder.

1. In your `bpaPrep` repo, make a folder named **`java_timed01`**.
2. Put `RockPaperScissors.java` in it.
3. Commit and push.
4. In the Google Classroom **BPA Friday** assignment, write a private comment: *Java timed build 1 done*.

---

## Grading

Graded with the rubric, then converted: 90-100 = 5, 80-89 = 4, 65-79 = 3, started but far off = 2, not turned in = 0.
