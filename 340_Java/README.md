# 340 Java Programming

**Format:** One program, 90 minutes, built on your own computer in a local Java IDE. Graded on: does it run (if it does not run, the execution section scores zero), does it do what the test says, and source code review (comments, exact variable names, required structures).

**Reference materials in the real test:** **Yes, including printed code.** You may bring printed reference materials and printed pre-written code. Nothing electronic, no online compilers, no old BPA tests.

**What the latest regional looked like:** The 2026 regional was a console arithmetic practice program: Scanner input with exact prompts, a switch statement, two while loops that had to end without `break`, random numbers, and the last two digits of your Contestant ID added to every listed variable name. The 2024 regional generated random records from a provided class and required numbered `SC` comment flags next to graded code. This event is the strictest about matching the sample output character for character.

## How to turn in

1. All your BPA work goes in your **`bpaPrep`** GitHub repo.
2. Each step gets its own folder: `java_step01`, `java_step02`, … `java_step11`. Timed builds go in `java_timed01` and `java_timed02`.
3. The file is `Step01.java` (with `public class Step01`), `Step02.java`, and so on. The file name must match the class name.
4. Commit and push with GitHub Desktop.
5. Add a private comment on the Google Classroom **BPA Friday** assignment, for example: *Java step 4 done*.

## How Fridays work for this event

- Do the **next** step you haven't finished. You keep track of which step you are on.
- Steps are not tied to dates. Some take one Friday, some take two.
- If you finish a step early, start the next one.
- After Step 11, do the timed builds in Step 12.
