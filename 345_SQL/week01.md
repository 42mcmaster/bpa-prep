# BPA 345 SQL — Week 01: Open-Book Form

## Overview
Answer 20 questions about SQL using the **printed study guide**. The point of this week is to learn where things are in the guide, because you can bring the printed guide into the real competition.

**Time Estimate:** 30-40 minutes for the Form, then 10-15 minutes of Gimkit

**What you need:**
- [345 SQL Reference Guide](345_SQL_Reference_Guide.md) (printed, or open in another tab)
- The Form link below

## Part 1: The Form (graded)

**Open the Form:** FORM LINK HERE

**Part 1 — Find It in the Guide (10 questions, 1 point each)**
Each question tells you which section of the guide to look in. Go there, find the answer, pick it.

**Part 2 — Read the Query, Predict the Result (10 questions, 2 points each)**
Each one shows a query against the guide's School tables (Section 3) and asks what comes back. Trace it row by row. Use the Table of Contents, the Trap List (Section 17), and the Quick Reference Card (Section 18).

**Rules:**
- Open book. Use the guide for every question.
- No Google. No AI. Just the guide.
- One submission. You will see an explanation for every question after you submit.
