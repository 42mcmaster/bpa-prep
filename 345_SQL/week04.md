# BPA 345 SQL — Week 04: Hands-On Lab: Real Queries

## Overview
Write real SQL queries against a database and enter the results. The notebook builds the database for you. The Form grades itself.

**Time Estimate:** 40 minutes, then Gimkit

**What you need:**
- [345 SQL Reference Guide](345_SQL_Reference_Guide.md), printed — Section 18 has every query pattern you need
- JupyterLab (Anaconda) on your lab PC
- [BPA345_SQL_Lab.ipynb](week04_lab/BPA345_SQL_Lab.ipynb) — download it

---

## Part 1: Set Up

1. Download the notebook and open it in JupyterLab.
2. Run the first cell. It builds a School database in memory: the same shape as Section 3 of the guide, with more rows. Nothing is installed.
3. Run the second cell to look at the three tables.

If you mess up the database, run the first cell again. It starts over.

---

## Part 2: The Tasks (graded)

**Open the Form:** FORM LINK HERE

- 20 numbered tasks in the notebook, 2 points each in the Form.
- For each task, **write the query yourself** in the cell under it, run it, and pick the matching result in the Form. Use `q("SELECT ...")`.
- Tasks 18-20 change the data (INSERT, UPDATE, DELETE). Do them in order.
- No Google, no AI. The guide is allowed.
