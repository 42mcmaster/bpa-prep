# BPA 335 C++ — Timed Build 2: Food Truck Sales

## Overview
A 90-minute production task in the shape of the real event. You get a problem, a starter file, a data file, and a rubric. Build it, make sure it runs, push it.

**Time Estimate:** 90 minutes

**What you need:**
- [Problem](TimedBuild02_Problem_FoodTruck.md) — read it all before you type anything
- [Starter file](TimedBuild02_FoodTruck_starter.cpp) — download it and build on it
- [sales.csv](sales.csv) — the data file the program reads
- [Rubric](TimedBuild02_Rubric.md) — this is how it is graded. Put the `// #SC1` … `// #SC5` flags next to the code the rubric names; no flag, no credit.
- The [335 C++ reference guide](../../335_CPlusPlus_Reference_Guide.md), printed, and your printed Step 10 input functions. You may bring printed references and printed code into the real event.

Use relative file paths only. An absolute path like `C:\\Users\\...` breaks on the grader's computer.

---

## Part 1: Build (graded)

1. Make a Visual Studio Console App project named **`cpp_timed02`** inside your `bpaPrep` folder. Paste the starter code into the `.cpp` file and rename the file **`TimedBuild02_FoodTruck.cpp`**. (g++ users: make a folder `cpp_timed02` and put the starter file in it with that name.)
2. Put `sales.csv` in the project folder. Also copy it next to the `.exe` (`x64\Debug`) once you have built once.
3. Build to the spec in the Problem file. Put your name in a comment at the top (at the real contest it is your contestant ID).
4. **Input / Processing / Output comments** on every major block. The graders look for them.
5. Save a running version often. **If it does not run at time-up, the execution section scores zero.**
6. No Google, no AI. Printed guide and printed code only.

---

## Turn It In

1. In your `bpaPrep` repo, the folder is **`cpp_timed02`**.
2. It must contain `TimedBuild02_FoodTruck.cpp` and `sales.csv` (Visual Studio: the whole project folder).
3. Commit and push.
4. In the Google Classroom **BPA Friday** assignment, write a private comment: *C++ timed build 2 done*.

Graded with the rubric, then converted: 90-100 = 5, 80-89 = 4, 65-79 = 3, started but far off = 2, not turned in = 0.
