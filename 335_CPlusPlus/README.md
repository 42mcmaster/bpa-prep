# 335 C++ Programming

**Format:** One console program, built in 90 minutes on your own computer. Graded on: does it run (if it does not run, the execution section scores zero), does it do what the test says, and source code review (comments, naming, required functions, validation). Put your contestant ID in a comment at the top. Use relative file paths only.

**Reference materials in the real test:** **Yes, including printed code.** You may bring printed reference materials and printed pre-written code. Nothing electronic, no online compilers, no AI, no old BPA tests.

The 2026 regional was a console menu with 5 options, one function per option: display a CSV as a table, generate passwords, reverse a sentence, calculator, exit. Validate every input. Relative paths only.

## How to turn in

1. All your work goes in **one GitHub repository named `bpaPrep`** in your own account (you already have it).
2. Each step gets its own folder: `cpp_step01`, `cpp_step02`, and so on (`cpp_timed01`, `cpp_timed02` for the timed builds). If you use Visual Studio, push the whole project folder; your `.cpp` file must be in it.
3. Commit and push with GitHub Desktop.
4. Write a private comment on the Google Classroom **BPA Friday** assignment, for example: *C++ step 4 done*.

## How Fridays work for this event

- Do the **next** step. You keep track of which step you are on.
- Steps are not tied to dates. Some take one Friday, some (8, 10, 11) take more.
- If you finish a step early, start the next one.
- After Step 10, do Timed Build 01. After Step 11, do Timed Build 02. Then the teacher has printed past regional tests for timed practice.
