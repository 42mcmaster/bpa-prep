# V03 Virtual Game Development Team

**Format:** Team of 2-4 builds an original endless-runner game titled "Afterburn" (a young inventor on a rocket skateboard through a futuristic city). Submit source code, art and audio, a game manual, and a working build. Judged online; no presentation.
**Reference materials in the real test:** Not a test. You build the project ahead of time and submit it online, then (for the judged events) present it to judges at the competition.

**Deadline:** Register by **December 1, 2026** ($20 per team). Submit by **January 15, 2027**, 11:59 PM Eastern, as one PDF with a link to the project files at upload.bpa.org.
**AI policy:** Allowed with citation (Level 2). Fill out the AI Usage and Documentation Form.
Team captain submits. Start with a one-page design doc: engine, who does what, and the minimum game that would run.
