# BPA Prep — MCCC IT Academy 2026-27

Everything for Friday BPA work is here. Find your event below, open its folder, and do this week's file.

## How Fridays work

1. Open the folder for each event you signed up for.
2. Open your **next** week file (`week01.md`, then `week02.md`, and so on). It tells you what to do and has the links. You keep track of which week you are on.
3. Do the work, then play the Gimkit.
4. In the Google Classroom **BPA Friday** assignment, write a private comment saying what you finished, for example: *Linux week 2 done, C# week 1 done*.

**Turning in builds.** Form weeks grade themselves. For anything you build (a web page, a program), make **one GitHub repository named `bpaPrep`** in your account and push each build to its own folder inside it (`html_week01`, `csharp_week01`, and so on). The week file tells you the folder name. Include the repo link in your first private comment.

Each week is one of four kinds, in a cycle:

| Kind | What you do |
|---|---|
| Open-book Form | Answer questions using the printed study guide. Practice finding answers fast. |
| Mini-test | Round 1 closed book and timed, like the real test. Round 2 same questions, open book. Round 2 is the grade. |
| Write the questions | Write 10 Gimkit questions from one section of the guide. The best ones go in next week's game. |
| Hands-on | Do it for real: terminal commands, SQL queries, or a timed build. |

**Print your study guide.** Most events let you bring printed reference materials into the real test. Not electronic. Not old BPA tests.
