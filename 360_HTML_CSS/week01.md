# BPA 360 HTML and CSS — Week 1: Notepad Setup and First Practice Build

## Overview
The real event is 25 multiple-choice questions plus a **90-minute build**: you get a spec and a screenshot of a finished page, and you recreate it in plain **Windows Notepad** with an external CSS file. This week you learn to work in Notepad, then do your first timed build from a real past spec.

**Time Estimate:** 25 minutes for the walkthrough, then 60-90 minutes for the build

**What you need:**
- A Windows computer with Notepad (not Notepad++, not VS Code)
- [360 Reference Guide](360_HTML_CSS_Reference_Guide.md), printed. You may bring printed materials into the real event.
- The practice spec in the `practice` folder (see Part 2)

---

## Part 1: Notepad Walkthrough

Do [Notepad_Walkthrough.md](Notepad_Walkthrough.md) from start to finish. Do not skip it even if you know HTML. The point is the Notepad habits: Save As **All Files**, save-then-refresh, typing every closing tag, external CSS only.

---

## Part 2: The Practice Build (graded)

Open the practice spec: **[practice/](practice/)** — Mr. McMaster will tell you which file.

It is a past regional test. Scroll to the **Application** section. There is a page of specifications and a screenshot of the finished page.

1. Make a new folder named `html_week01` (this is the folder you will push later).
2. Build the page in Notepad: `index.html` and `styles.css`, exactly as the spec says. Match the screenshot.
3. For the logo, use any image and name it what the spec expects. The real image is not included.
4. Work like the contest: 90 minutes, printed guide only, no Google, no AI.

**The rules the graders check, every time:**
- Valid HTML5. Every tag closed.
- All styling in the external CSS file. No `<style>` tags, no `style=""` attributes.
- No tables for layout.
- The `<title>` matches the spec exactly.
- Colors, fonts, sizes, margins match the spec exactly.

---

## Part 3: Turn It In

All BPA builds go in **one GitHub repository named `bpaPrep`** in your own GitHub account. Make it once (public, like your class repos). Each build gets its own folder.

1. Take a screenshot of the finished page in the browser (Windows + Shift + S). Save it as `screenshot.png` in your build folder.
2. In your `bpaPrep` repo, make a folder named **`html_week01`**.
3. Put `index.html`, `styles.css`, your image, and `screenshot.png` in it.
4. Commit and push.
5. In the Google Classroom **BPA Friday** assignment, write a private comment: *HTML week 1 done*. Include the link to your repo the first time.
