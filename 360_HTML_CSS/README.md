# 360 HTML and CSS Coding

**Format:** Multiple-choice questions plus hand-coding a page from a spec. 90 minutes. You get a browser and plain Notepad only (no Notepad++, no editors with autocomplete). This event used to be called 415 Fundamentals of Web Design.
**Reference materials in the real test:** **Yes.** Printed reference materials. No electronic devices, no old BPA tests.

Practice typing HTML and CSS without autocomplete. The real event is in Notepad.
